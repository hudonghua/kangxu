# FSJ_666 程序框架与显示问题复核

复核日期：2026-10-04。范围是实际使用的 FLASH 工程和本次显示修复。已核对源码框架、共享状态、任务顺序及最终调试 BIN；硬件串口波形、屏幕效果和整机动作尚未观察。其他原有隐患仅记录，没有扩大修改。

## 运行流程

遥控器开机读取参数，扫描开关和摇杆，向无线模块与 CAN 总线发送数据。主界面根据本地臂选择开关显示左、中、右臂的四个距离；数值来自接收机无线回传，单位 mm。急停、使能和电源控制另有自己的处理流程。

~~~mermaid
flowchart TD
    A["上电初始化、读取参数"] --> B["欢迎画面与输入检查"]
    B --> C{"电源检查是否异常"}
    C -- 正常 --> D["主界面背景发送8次"]
    D --> E["最后一包后等待200个1ms节拍"]
    E --> F["绘制文字、距离和状态图标"]
    C -- 异常 --> G["状态检查页面"]
    F --> H["周期运行：输入、通信、界面"]
    G --> H
    H --> I["本地左／中／右臂选择"]
    I --> H
    H --> J["急停／未使能：无线安全处理"]
    J --> H
    H --> K["背光、欠压及断电处理"]
~~~

这是程序设置的等待时间，不能证明屏幕实际完成切换。当前流程没有读取屏幕“背景切换完成”的应答。

## 本次教训与修正

原需求只涉及开机时序：主界面背景从4次改为8次，最后一包后等待200ms，再绘制文字。此前没有彻底核实当前源码和现场旧固件的显示路径：当前源码的 MainLogic 中 display 原本被注释，第一份时序修改 BIN 因而缺少这部分文字。之后恢复调用时，只检查文字绘制，漏查了所读开关变量会被安全发送逻辑修改。

~~~mermaid
flowchart LR
    A["开关输入"] --> B["1ms扫描、去抖"]
    B --> C["本地原始扫描状态"]
    C --> D["复制为发送状态"]
    D --> E["未使能／急停时清零"]
    E --> F["旧显示读取零：误判中臂"]
    C --> G["修正显示读取原始快照"]
~~~

无线处理在同一轮主循环的屏幕刷新之前执行。如果安全发送清零后，下一次中断扫描尚未重新赋值，旧显示便把左、右臂当成中臂。这个关系已在真实扫描和发送函数的主机检查中复现。现场中断插入时机尚无硬件测量。

## 页面、自检与安全退出

- 正常主页面：9到2共8包PIC31；末包设1并返回，重置计时；下一完整200ms节拍画字；之后每200ms刷新。
- 电源异常：main选择Disp_ZZT_CtrlStatus，背景PIC7；共享开机计数9，但该页面没有新增的主页面200ms末包等待。
- 主页面：F1亮度、F1+F3状态页、F1+F4参数入口；F3单键换页调用原本是注释。臂选择更新标题/数据，不改变页面函数指针。
- 状态页：开关/摇杆数据及Arm_Study；F4回主页面，F1+F4进入参数入口。
- 参数/密码页：按已有函数指针及下一页指针流转，保存标志由主循环写EEPROM。本次未改密码、标定或参数。
- 自检：0延时→1检测→2运行；从未连接持续检测，连接后掉线重检。dly++>30约32个10ms调用；掉线延时还叠加1s信号统计，不能按注释认定精确时间。
- 急停：无线中位127、DI清零、尾字节0x55；背光立即关闭，使能取消；约5s关屏/无线，>10s关CPU。未使能安全包尾字节0xaa。
- 急停释放/无操作唤醒：已有800ms延时和gLcdFresh=2，不会设成开机9；主页面末包等待仍走同一路径。
- 欠压/无操作：wl_lcd_power/T0S_Prog控制电源；不能把所有黑屏都归为绘图问题。

## 通信边界

UART0无线、UART1屏幕，均115200。无线有效载荷19字节；安全分支保留中位127、DI清零与模式/机型/安全字段；Uart0_WL_Send加头、类型和校验并另发CAN镜像。UART1有接收中断缓存，但当前主循环没有消费屏幕完成应答。

CAN1当前周期入口是Can_Send_Prog，不能与未调用的旧Can_Prog_Send分支混淆：

| ID | 数据 | 阈值与名义周期 |
| --- | --- | --- |
| 0x188 | 8轴Y_Send | >5，约60ms |
| 0x189 | ADC0..3 | 同上 |
| 0x18A | DI四字节、ADC4/5 | >10，约110ms |
| 0x18B/0x18C/0x18D | 其余ADC字段 | 同上 |

10ms分支先发再更新，发送前一轮转换值。配置ID、0x1C8/0x1CA接收与无线距离回传是不同来源；不能仅按display里的协议注释认定距离由对应CAN ID更新。CAN2未在main初始化，gCan2InitFlg=0时退出对应后续中断路径。
